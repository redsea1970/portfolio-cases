# Кейс 1: Анализ отзывов клиентов с помощью LLM

## Контекст
- Домен: e-commerce / SaaS.
- Роль: промт-инженер / аналитик.
- Проблема «до»: отзывы анализируются вручную, занимает часы.

## Задача
Автоматизировать анализ отзывов: выделить темы, боли, инсайты, вернуть JSON.

## Подход
1. Использован JSON-шаблон `01_review_analysis.md`.
2. Модель размечает отзывы по темам и категориям.
3. Результат валидируется на корректность JSON.

## Эффект
- Время анализа сокращено с 2 часов до 10 минут.
- Структурированный JSON позволяет строить дашборды.

## Ограничения
- Ошибки на сарказме и смешанных отзывах.
- Нужна ручная проверка критичных выводов.
