# Промт для анализа отзывов

Вы — аналитик продукта. Разберите отзывы и верните JSON.

Контекст: онлайн-сервис для планирования тренировок.
ЦА: мужчины и женщины 25–40 лет, офисная работа, мало времени.

Отзывы:
1. Отличный сервис, всё работает быстро.
2. Заказ пришёл поздно, упаковка повреждена.
3. Пока не могу оценить.
4. Товар хороший, но доставка заняла вечность.
5. Спасибо за помощь в выборе!

Требования:
- Объединить близкие отзывы в темы.
- Категории: bug, feature_request, usability, pricing, performance, praise, other.
- Для каждой темы: описание, категория, примеры, важность (1–5), влияние на бизнес.

Формат ответа — JSON.
