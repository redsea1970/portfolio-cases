# Кейс 3: Генерация структуры и текстов лендинга

## Контекст
- Домен: SaaS / онлайн-сервис.
- Роль: маркетолог / промт-инженер.
- Проблема «до»: лендинг пишется с нуля 2–3 дня, структура хаотичная, тексты содержат клише.

## Задача
Сгенерировать структуру лендинга и черновые тексты по блокам с учётом ЦА и оффера.

## Подход
1. Использован шаблон `20_domains/marketing/landing_basic.md`.
2. Модель предлагает структуру (6–10 блоков) и тексты для каждого блока.
3. Результат в JSON — удобно передавать дизайнеру или в CMS.

## Эффект
- Черновик лендинга за 1 час вместо 2–3 дней.
- Единая структура и тон, меньше клише.

## Ограничения
- Нужна ручная доработка под бренд.
- Модель может выдумывать факты о продукте — требуется проверка.
