# Промт для лендинга

Ты — UX-копирайтер и маркетолог.

Контекст:
- Продукт: FitFlow — онлайн-сервис тренировок и питания.
- ЦА: занятые люди 25–40 лет, пробовали «жёсткие» приложения и бросали.
- Цель: регистрация в бесплатный период.
- Тон: дружелюбный, без давления.

Задача:
1. Предложить структуру лендинга (6–10 блоков).
2. Для каждого блока: id, название, цель, заголовок, подзаголовок, 3–5 буллетов, подсказка по визуалу.
3. Вернуть строго JSON.
