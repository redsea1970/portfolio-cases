# Кейс 2: Еженедельный отчёт по продажам с помощью LLM

## Контекст
- Домен: e-commerce.
- Роль: аналитик / промт-инженер.
- Проблема «до»: отчёт собирается вручную в Excel, занимает 1,5–2 часа в неделю, часто с ошибками в цифрах.

## Задача
Автоматически генерировать черновик отчёта из агрегированных метрик: считать изменения, формулировать выводы и рекомендации.

## Подход
1. Использован JSON-шаблон `05_weekly_report.md`.
2. Модель считает проценты, формирует summary, гипотезы и рекомендации.
3. Результат возвращается в JSON для дальнейшей автоматизации.

## Эффект
- Время подготовки отчёта сокращено с 2 часов до 15 минут (проверка черновика).
- Единый формат отчётов, меньше ошибок в цифрах.

## Ограничения
- Модель может ошибаться в интерпретации причин.
- Требуется ручная проверка цифр (валидация).
